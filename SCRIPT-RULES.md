# Script rules

A reel is 35–50 s (the 15 s cut still exists). There is no room for a line that does not
earn its place.

## The eight rules

1. **Every beat is new information or a reversal.** Never describe what the picture already shows.
2. **Hook in the first 2 s:** a number, a contradiction, or one specific detail.
3. **Cold open.** The situation already started before frame one.
4. **Three escalations, then the reveal.** Each beat bigger than the last.
5. **One wordless gag** — the reel must still work muted.
6. **Delete the last line if it explains the beat before it.**
7. **The punchline is 1.5 s, then cut.** No "send this to…" unless the reel earned it.
8. **Ten hooks written, one picked.** The other nine are never rendered.

## Reference fix

Before (the-draft):

> "Hey." / "No." / "Heyyy." / "Too much." / "Hey." / "He's typing." / "He said: I'm outside."
> Kicker: "He was already outside."

After:

> types `hey` → deletes · `heyy` → deletes · `heyyyy` → deletes · sends `hey`
> three dots… they stop · she sets the phone down · **knock at the door**
> Kicker: **"He'd been outside for 20 minutes."**

Every beat is a turn, the punchline arrives as a sound, and the kicker adds information.

## Filler that gets cut

- "He was already…", "It's just…", "I mean…", "You know…"
- any line that repeats the previous beat in different words
- any line explaining the emotion ("I was so sad")
- setup lines ("So, here's what happened")

## Hook shapes that work

| shape | example |
|---|---|
| number + noun | "He rewrote one word 11 times." |
| contradiction | "You're early." (she has been there two hours) |
| forbidden detail | "The last bus left 20 minutes ago." |
| consequence first | "She found the letter three years late." |

## Before shipping, answer

- Would this survive muted? (rule 5)
- Does the last line add something the viewer did not know? (rule 6)
- Is there exactly one idea? (rule 1)
- Could any line be replaced by a look, a sound, or a gesture?
